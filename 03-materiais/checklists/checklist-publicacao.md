# Checklist — Publicação

- [ ] Build/deploy concluído sem erro.
- [ ] Variáveis cadastradas no ambiente de produção.
- [ ] Nenhum `.env` foi versionado.
- [ ] RLS e acesso somente pelo servidor revisados.
- [ ] Webhook valida assinatura.
- [ ] OAuth usa URI de produção.
- [ ] Páginas legais acessíveis.
- [ ] Aplicativo no modo correto.
- [ ] Token e renovação verificados.
- [ ] Fila possui trava contra duplicidade.
- [ ] Ritmo de envio configurado de forma conservadora.
- [ ] Logs e falhas podem ser acompanhados.
- [ ] Teste real concluído.
- [ ] Mensagens não incentivam spam.
- [ ] Documentação atual da Meta consultada.
