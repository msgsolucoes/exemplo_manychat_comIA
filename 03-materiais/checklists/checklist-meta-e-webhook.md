# Checklist — Meta e webhook

- [ ] Aplicativo criado no Meta for Developers.
- [ ] Produto correto do Instagram adicionado.
- [ ] Instagram profissional preparado.
- [ ] URI OAuth cadastrada.
- [ ] Variáveis secretas configuradas somente no servidor.
- [ ] Callback do webhook cadastrado.
- [ ] Verify token configurado.
- [ ] Handshake do webhook validado.
- [ ] Assinatura `X-Hub-Signature-256` validada no servidor.
- [ ] Campos `comments` e `messages` assinados quando aplicáveis.
- [ ] Testador adicionado e convite aceito, se necessário.
- [ ] Política de privacidade publicada.
- [ ] Instruções de exclusão de dados publicadas.
- [ ] Modo do aplicativo adequado ao cenário de teste/produção.
