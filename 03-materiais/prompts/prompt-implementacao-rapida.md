# Prompt — Implementação rápida a partir do fork

```text
Analise este fork antes de fazer alterações. Quero obter uma primeira versão personalizada sem reconstruir o projeto do zero.

Minha oferta/material: {OFERTA_OU_MATERIAL}
Palavra-chave: {PALAVRA_CHAVE}
Resposta pública: {RESPOSTA_PUBLICA}
DM inicial: {DM_INICIAL}
Texto do botão: {TEXTO_DO_BOTAO}
Link: {URL}

Faça nesta ordem:
1. Leia a documentação e a estrutura do repositório.
2. Diga quais funções já existem e o que ainda precisa ser configurado externamente.
3. Verifique como executar e testar localmente.
4. Proponha apenas as adaptações mínimas para os textos e o fluxo acima.
5. Antes de editar, confirme que nenhum segredo será incluído no código ou no Git.
6. Depois de cada alteração, execute as validações disponíveis no projeto.

Não afirme que Meta, OAuth ou webhook estão funcionando sem um teste real. Não implemente disparo em massa ou recursos incompatíveis com a API oficial.
```
